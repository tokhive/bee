## 共同契约与阶段边界

- 每票都应形成可独立验证的完整用户行为，包括真实层、必要公开状态、严格解码、前端衔接和失败／未知结果恢复；11 负责入口整合及证据汇总。
- 准备账号、重连与登录后恢复均须先让本机转发就绪，再发布当前连接的可用授权。新暂停优先于旧恢复，未知写入只核对不重放。
- 暂停接单是同一 Hive 用户的目标平台选择，不能描述为本设备独有；不新增日常总接单开关。
- 01–09 在受控原生验证中逐步完成；11 在依赖完成后切换正常入口并验收，避免部分实现提前替代现有可靠流程。
- 09 已确认：旧 false 且有选择的账号先统一确认平台暂停，再启用自动维护；仅转换一次。10 仍为 needs-info，现有协议无法取回未知创建时未拿到的原 token。
