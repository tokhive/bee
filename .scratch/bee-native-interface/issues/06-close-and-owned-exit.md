# 06: 关窗后台运行，明确退出可靠停止

**What to build:** 用户关闭窗口后服务继续运行并可找回；明确退出时自动恢复被抑制，Bee 回收本 App 拥有的工作与连接，保留平台接单选择。退出可能中断任务，结果必须如实记录。

**Blocked by:** 02 — 接入账号后自动维护，平台保持暂停接单。

**Status:** ready-for-agent

- [ ] 关闭主窗口不会停止维护或改变平台接单选择；通过当前系统支持的入口能够重新找回原窗口与最新状态，不创建第二个管理实例。
- [ ] 明确退出先抑制自动启动与恢复，再回收本 App 拥有的授权维护、转发、登录子进程和连接；退出不能被迟到重连或准备回调抵消。
- [ ] 仅回收当前 App 拥有的资源，不按进程名查杀外部 Bee，也不抢占无法证明归属的进程。
- [ ] 明确退出不把平台接单选择改为另一个日常总开关；用户停止、App 退出和维护重启等意图不能相互覆盖或伪造干净恢复证据。
- [ ] 提示可能中断已有任务，不新增等待全部任务完成的承诺；回收本机工作、保存意图和清理会话的结果分别可信。
- [ ] 保存或回收失败时保留实际环节及证据，不能先显示干净成功；若进程已经退出，诊断中仍能核对失败，不能仅依赖已消失页面的反馈。
- [ ] 沿用已有原生入口并贯通所需公开状态；验证等待接入、双平台运行、准备中及登录中关窗／退出，覆盖迟到回包与保存失败，并分别记录原生系统与受控测试证据。
