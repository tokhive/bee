# 07: 应用网络配置后受控恢复服务

**What to build:** 用户测试、保存并确认应用网络设置后，Bee 在需要时受控重启自有服务，并按新配置恢复维护及原平台接单选择。取消、应用失败或结果未知时，用户能看清保存值与实际生效值并继续处理。

**Blocked by:** 03 — 重启、重连与后台刷新保留接单选择；06 — 关窗后台运行，明确退出可靠停止。

**Status:** ready-for-agent

- [ ] 草稿测试不保存或替用户应用配置；保存和生效分别反馈，明确显示实际配置、保存修订及待重启状态。
- [ ] 只有当前有效配置与明确确认进入应用流程；取消不停止服务，不把旧确认应用到后来修改的配置。
- [ ] 需要重启时先执行受保护的停止与交接，完成后按已核验新配置恢复；自动恢复不能抢在停止完成、配置验证或用户退出之前发生。
- [ ] 恢复后保留各平台当前接单选择，暂停平台仍暂停；身份、来源或连接未核验时不宣称可接单，不发布尚未就绪的可用授权。
- [ ] 网络应用不重放未决账号、登录或接单写入；原结果未知时保留原操作和配置证据，通过查询核对，不反复提交配置应用。
- [ ] 同一 Hive 用户的平台接单选择不因代理失败被改写；明确退出、更新安装或新的配置修订能阻止旧应用回调继续拉起服务。
- [ ] 公开保存／生效／停止／恢复与失败状态贯通严格解码和页面；连续验证保存后取消、确认应用、配置失败、停止失败、响应丢失及恢复后继续，原生进程证据与 mock 结果分别记录。
