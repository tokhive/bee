# 08: 更新安装复用可靠退出流程

**What to build:** 用户检查或下载更新时继续使用服务；确认安装后，Bee 可靠停止自有工作并交接给安装流程。版本、校验、停止或安装失败均有真实结果，自动服务不会与安装竞争。

**Blocked by:** 06 — 关窗后台运行，明确退出可靠停止。

**Status:** ready-for-agent

- [ ] 检查及下载更新不停止维护、不改变任何平台接单选择；页面按真实下载与校验进度展示状态。
- [ ] 仅在目标版本、校验结果、操作身份与修订仍有效且用户明确确认后安装；旧确认、重复点击或旧下载回包不能安装另一份内容。
- [ ] 安装复用自有资源退出与回收规则，停止前抑制自动恢复；停止或退出证据不完整时不继续安装，不伪造成功。
- [ ] 已开始的安装不会被迟到连接、自动准备或网络应用回调重新拉起旧服务；检查、下载和安装的状态不能互相覆盖。
- [ ] 失败保留具体环节、可公开证据和有效下一步；结果未知时核对原过程，不重复安装或盲目重放停止操作。
- [ ] 不为安装改写平台接单选择，不承诺等待任务排空；恢复后接单选择的组合行为由 11 联调验证。
- [ ] 同步公开状态与严格契约，覆盖检查／下载不中断、有效安装、旧修订拒绝、停止失败和安装失败；受控测试与最终候选包的签名／系统安装证据分开记录。
