# 按 Hive URL 区分桌面绑定

2026-11-12，用户确认本阶段按 Hive URL 区分环境，补齐 A → B → A 的绑定切换。各 URL 保存独立绑定，切回时核验并使用原绑定；主机名大小写、默认端口和末尾斜杠统一，不同主机名及非默认端口分别保存，历史冲突不自动覆盖。完整边界见[切换设计](../desktop/designs/2026-11-12-hive-url-switching.md)。

采用此边界可以覆盖当前不同地址间往返的需求，无需先为 Hive 增加实例身份协议。同一 URL 更换数据库不能由 URL 判断为新环境，凭证被拒绝也不能等同于凭证已撤销；该限制保留在恢复流程中。将来引入 Hive 实例身份时，需要明确旧 URL 绑定的迁移规则。
