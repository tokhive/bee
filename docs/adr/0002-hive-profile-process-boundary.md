# 按 Hive 绑定隔离存储与后台进程

2026-11-12 用户确认：每个 Hive 的凭证、账号、运行保护和恢复事务成套隔离。采用独立绑定目录、固定目录的后台进程及单个 App 级切换协调器；准备目标期间最多保留一个权限受限的目标后台，仅用于配对、核验和安全激活所需的设备屏障操作，同时只有当前 Hive 可以贡献。

这样可以复用现有单绑定核心的锁和恢复边界。只替换当前配置不能保证恢复记录归属；让一个核心同时容纳所有 Hive 则需要改写更多生命周期假设。代价是新增后台交接、迁移及切换记录，旧入口也必须在迁移后阻止旧程序继续写入。详见[已批准设计](../desktop/designs/2026-11-12-hive-url-switching.md)。
