### 最新规则变更：接入保留原有接单状态

✅ 已确认：接入、准备及失败重试不改变原有暂停／允许接单选择；结果核对成功也按该选择继续。主动重新登录、确认换号后的暂停规则不变。

✅ IN-11 已确认：自动核对之外提供“核对结果”，仅查询原接入流程；已接入而未准备完成则转准备状态。✅ IN-12 已确认：确无历史接单选择时默认允许，确认页明确告知；查询失败不算无历史。

✅ 最新流程方向：准备期间临时暂停，完成后按原有／期间最新选择继续；不再以“删除暂停调用”为当前待定方案。❔ 接口侧负责防覆盖、失败恢复及无历史判别的实现核验，尚未据此完成业务验收。

HTML 状态：当前草稿已模拟保留接单选择，首次登录专项已认可；主预览仍为此前版本。真实接口和正式代码未据本次文档同步验收。

### 步骤展示：已确认，HTML 覆盖见最新专项记录

数字圆圈始终保留编号：完成绿色、失败红色、当前进行中强调色、未开始灰色；不替换为对勾／感叹号，不叠加图标。正文文案说明实际状态，避免仅依赖颜色。

### 范围与状态口径

覆盖当前已讨论的 OpenAI 账号操作、其可见子场景，以及契约揭示但尚未评审的分支。不是“所有条目均已确认”的需求清单，也不宣称穷尽未来业务条件。Claude、设备配对及其他页面不在本章范围。新增事实或确认后更新对应条目，不靠聊天记录追踪。

- **设计**：已确认＝用户认可的文本或明确认可的预览范围；部分确认＝原则或主流程已定，局部分支未闭合；待评审＝已有草案／契约样本，未获页面确认；尚未展示＝尚无完整页面方案。
- **HTML**：主预览＝已认可起点；流程内＝已有流程演示，但缺独立子场景或未同步最终文案；草稿＝局部候选，未认可；未制作＝无已核实的对应预览。不能将流程内可到达视为已提供独立入口。
- **接口**：待核实＝本次未完成该场景端到端接口映射，不等于接口不存在；部分已有＝既有命令存在，完整交互仍依赖待实现扩展；仅契约＝类型／样本已定义，未实现；存在缺口＝恢复或安全边界仍未闭合。
- **真实验收**：本章全部条目均未据本轮文本、HTML 或静态样本完成真实业务验收。已有测试不替代真实登录、暂停生效或换号持久化验收。
- 表格将设计确认状态放在首列，各类操作内优先排列尚未展示、待评审和部分确认项；编号保持不变。✅ 只代表所在列，不代表整行已完成。❔ 待核实不等于缺失。相同结果由不同操作进入时保留入口差异，不重复定义业务规则。

预览依据：[主预览](../preview/index.html)、[候选稿](../preview/draft.html)、[预览覆盖说明](../preview/README.md)、[历史索引](../preview/history/README.md)。当前主预览独立入口为首次接入、授权过期且暂停后的恢复、可接单，以及额度等待的 16 个状态／详情组合。其他旧模拟不能据此整体认定已确认。

接口依据：登录恢复核对契约提交 `325b1b0`；一次重新登录复合契约提交 `d4c4b49`。后者已交付契约、类型和静态样本，不能沿用“仍只有未提交草稿”的历史判断；restart／status／cancel、progress／open 扩展均未实现。设计记录中的早先核对时间点不等于当前交付状态。

### 组合规则与后续补齐顺序

- 暂停／恢复选择独立于额度；正常重连、后台刷新、重启和读取权限修复保留最新选择。接入保留原有接单选择；主动重新登录和确认换号后保持暂停。组合状态沿用这些规则，不将每种组合重复计为新需求。
- 读取失败、token 刷新不等于发现新账号；只有成功读取到不同身份才进入换号。查看详情、打开设置或安装说明不触发假修复。
- 每个可见阶段、结果和弹窗最终均需独立子场景；本清单中并列列出的分支实施时应分别可选择。直接选择停留，产品按钮推进，切场景取消旧模拟任务；主题和尺寸保留操作状态。详见 [HTML 预览规范](../standard/html-preview.md)。
- 接入类 IN-11、IN-12 及 LOGIN-01、03～08、12 已完成文本确认；LOGIN-13～15、RE-07 和 RE-10 页面方向也已确认；RE-11～14 已在 2026-11-09 确认；相同页面直接引用已确认场景，只评审新增差异，不重复整页确认。SUP-13～15、AUTH-04、VIEW-01、VIEW-05 也已确认；后续汇总并核对接口缺口，获用户明确要求后制作 HTML，再实施正式 UI 与真实验收。优先核实接入／接单长期未知、RE-10 安全重试、取链及重新核验、设置保存和准备进度。契约列出的分支不自动成为已确认页面方案。
- 重登契约的已知真实缺口包括受控进程停止证明、持久去重与占位、安全移交、旧浏览器页面与端口隔离、外部存储迟到写入等，详见契约，不把它们全部拆成产品按钮或宣称已解决。
- 最后按明确授权整合 HTML 和独立子场景，再开展正式 UI 接口接入及真实业务验收。本次仅建立索引，没有更新 HTML、mock 或正式代码。
