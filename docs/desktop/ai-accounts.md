# 桌面 AI 账号管理

原生「AI 账号」页现在可以检测已有登录、启动官方登录、确认接入和换号；概览可以开始或停止本机贡献。Go 核心执行真实连接、授权同步和转发，页面分别显示管理进程、本机运行、Hive 连接及各平台状态。重启会核验已保存意图，首次使用和用户明确停止后不自动贡献。完整移除和等待 Hive 在途任务退出仍按批准范围暂缓，不修改 Hive。

## 怎么使用

1. 在概览完成设备配对。设备配对确认本机归属，不等于已登录 AI 账号或开始贡献。
2. 进入「AI 账号」，在 OpenAI 或 Claude 下点击「检测已有登录」。默认目录、公开快照和 Hive 核对不主动打开新的官方凭证；首次读取来源必须由你点击。需要其他目录或存储时，展开「高级来源」修改并重新检测。空目录表示使用官方默认命名空间。
3. 没有登录时点击「官方授权」，确认可能改变官方客户端当前账号。Bee 调用已安装的 Codex／Claude 固定登录入口；你在官方页面完成登录。运行贡献期间先停止贡献。可以取消本次登录；完成后只成为候选，尚未接入或贡献。
4. 检查候选身份与来源，点击「接入账号」并确认。Bee 核验设备、来源并暂停该平台后保存选择，显示「已选择，待开始」。暂停影响当前 Hive 账号下的该平台，不只影响本窗口。
5. 回到概览，勾选本次允许恢复接单的平台，再点击「开始贡献」。Bee 核验已选账号、连接 Hive 并同步授权；只有明确勾选且核验通过的平台才恢复接单。两个平台分别反馈，一个失败不把另一个标成失败。管理进程已就绪不等于贡献已运行。
6. 平台供给区可以暂停／恢复。暂停不终止在途请求；恢复解除平台准入暂停，尚未开始贡献时仍需明确开始。换号未决的平台禁止恢复，但可以安全暂停并核对状态。
7. 官方客户端换了账号后，重新检测候选并点击「确认换号」。Bee 核对旧账号、新账号及 Hive 待确认代次；成功后仍保持暂停，由你决定恢复。未注册的本地选择可以撤销，已注册账号完整移除暂不支持。
8. 「检查账号」发起官方只读身份／额度查询；「查看详情」分别显示本地候选、官方观察、Hive 当前／候选账号、额度窗、模型与更新时间。「刷新 Hive 状态」只核对状态，不重新检测来源，不自动重放接入或换号写操作。
9. 「停止贡献」需确认可能中断当前任务，成功后下次打开保持停止。正常退出会回收本 App 创建的运行并保留此前运行意图；下次打开重新核验后恢复，手动暂停和换号暂停保持。异常退出、未决操作、损坏状态及无法证明的停止结果均阻止自动恢复。

结果未知时，按钮会阻止重复写入；先点击重新核对。只有后端明确证明换号确认**尚未提交**时，才允许再次点击「确认换号」继续同一操作。正在提交账号操作时来源编辑锁定，避免把旧候选用于新目录。

不要将密码、验证码或 token 填入 Bee；本页只接受目录和受控存储选项。系统通知由 S2 接入，本分支的问题仍在应用内显示。实际官方授权及受控流量的未验证项见[验收记录](account-runtime-validation.md)。

## 来源、时效和失败

OpenAI 默认目录依次取 `CODEX_HOME`、用户目录下 `.codex`。`auto` 先读固定 `auth.json`，仅文件确实缺失且系统为 macOS 时才尝试 keyring；损坏或权限拒绝不回退。Claude 使用既有独立目录／NFC／Keychain 命名空间规则，`file` 与 `keychain` 不互相回退。macOS 以外的 Keychain 选项标记为不支持。本轮三端真实来源验收仍未完成。

编辑来源立即隐藏旧候选和官方观察；迟到结果不能覆盖新来源。候选只存在于当前管理实例，重新检测替换其修订号和随机引用，进入到期前 30 秒即失效。未知套餐显示未知，不能从套餐文字猜身份或接单能力。

官方观察按来源、指纹和凭证版本隔离：正常间隔 5 分钟、有效期 6 分钟、元数据缓存 5 小时，429 服从 `retry_at`。重复读取不能刷新原观察时间。单独的 profile 查询失败保留仍有效的独立额度结果，同时显示此次失败。额度百分比保留 120% 等原值，进度最多 100%，剩余最少 0；null 表示未知。专属 Opus／Sonnet 窗耗尽不能推导整个平台耗尽。

Hive 观察执行身份核验和 account → capabilities → account 夹读，核对指纹、generation、credential_revision、状态及未决账号。变化时整组未确认，不能混用两个账号的数据。`rate_limited` 是独立的当前事实，历史额度过期不会覆盖它。账号支持模型、市场开放、当前接单条件分别显示；没有可信市场接口时保持未知。

供给 GET 串行执行，成功后等 10 秒再刷新；概览与账号页之间切换不重建状态，离开这两页停止轮询。30 秒以上、核对中、失败或未核验状态禁止写入；每次实际发送全部操作中的下一项前也重查门禁。未知写结果停止自动刷新，用户点击重新核对仅发送 GET，不自动重放 PUT。

错误保留本次失败的检查点、HTTP 状态或系统证据，不回显官方正文、token、JWT、邮箱、confirmation_id 或连接 lease。一个子域失败不冒充其他子域失败或成功。

## 本地记录与命令

`ai-accounts.json` 位于独立桌面设备配置同目录，当前版本 2。保存提醒去重、按 Hive／owner／device 隔离的来源选择、未决操作、运行意图及会话标记，不保存 token。同目录独立的 `runtime-session` 标记在活动会话前保存；账号文件读写失败时也阻止不明会话自动恢复。旧 v1 首次写入升级前保存受保护备份。文件受私密权限、禁止跟随符号链接、原子替换和读回保护；损坏或未知版本不会被静默覆盖。

提醒按 Hive／owner／platform／指纹／问题类型去重，设备只参与归属核验。持续离线满 60 秒才提醒；明确恢复后再次异常可以重提醒，未知和陈旧观察不当作恢复。写去重记录失败时保留问题并说明持久化未确认。重启从受保护的选择和运行意图恢复，历史观察本身不能证明已选择或贡献中。

账号相关的四个固定命令如下；另有运行快照／开始／停止和官方登录开始／查询／取消，详见[管理协议](bridge-protocol.md)：

| 命令 | 固定参数 | 行为 |
| --- | --- | --- |
| `account_defaults` | `{}` | 仅返回默认目录和存储能力 |
| `account_detect` | `platform,directory,store,mode` | `mode=local/official`，必须显式给出 `directory:null` 或绝对目录 |
| `account_snapshot` | `platform,refresh` | false 仅公开快照；true 只刷新 Hive |
| `account_action` | `platform,revision,candidate_ref,action,confirmed` | 严格校验；select／clear_selection 已有真实保存与暂停核对，confirm_change 已接通真实暂停、确认及同步核对；完整移除仍不可用 |

Go 操作总期限 12 秒；Rust 账号请求从进入队列起共 15 秒。未发出的排队超时不破坏健康会话；已发送超时先撤销 ready，拒绝迟到成功和后续排队写。前端仅使用 typed 命令，不扩展 generic `bridge_request` 的 ping 权限。

公开快照固定含 `platform/revision/operation/candidate/selection/hive/authorization/capabilities/features/issues/checked_at`。Hive 额外公开 `pending_fingerprint/generation`，不公开 confirmation_id。能力按 official、hive 两项排列；所有时间为 UTC RFC3339（可含 1–9 位小数）或 null。前端逐字段解码，未知字段、错类型和错误实例不能进入视图。

## 官方登录适配（S1-T4）

调用 `authorize_start` 后，Bee 检查官方客户端版本与登录能力，启动固定命令，等待完成，再重新读取已选来源。启动前应说明“这可能改变官方客户端当前登录账号”；贡献运行期间先停止贡献，避免在维护中替换凭证。登录成功只产生候选，用户仍须确认接入。退出零但来源未变化、来源在核验中再次变化、官方核验失败均不显示成功。OpenAI 的本地结构核验不冒充在线身份核验；Claude 使用官方 profile 核验身份。

| 平台 | 固定命令与存储 | 版本适配范围 |
| --- | --- | --- |
| OpenAI | `codex login -c cli_auth_credentials_store="file"` 或 `"keyring"`；固定 `CODEX_HOME`；auto 登录写 file，keyring 仅 macOS | Codex CLI 0.162.x／0.163.x，且 help 必须包含 login |
| Claude | `claude auth login --claudeai`；macOS keychain、其他系统 file；自定义目录同时传给官方配置和安全存储命名空间 | Claude Code 2.1.x，patch ≥153，且 help 必须包含 --claudeai |

可信安装候选依次为用户 `.local/bin`、Unix Homebrew／`/usr/local/bin` 和 PATH 中的绝对可执行文件，解析符号链接；Unix 拒绝组／其他用户可写文件，Windows 只接受 `.exe`，不执行 `.cmd` 包装。缺少或版本不支持时显示具体缺项，用户安装官方客户端后重试，不由 Bee 自动安装。官方客户端网络沿用自身设置及环境代理；Bee 的专用代理不会注入登录过程。会移除继承的 API key/token 登录覆盖环境项。

Go 保有独立进程生命周期：Unix 使用固定 supervisor 保留进程组编号，结束后先清理受控组再回收；Windows 挂起创建、加入独立 Job 后再启动，取消终止本次 Job。正常退出也清理遗留的受控子进程。没有按程序名查杀；已有官方客户端不在本次生命周期内。启动、查询和取消都返回不含秘密的 operation；取消只有在回收后才成为终态，不能撤销已完成的官方登录。授权 URL、stdout/stderr、token、完整可执行路径不转发前端。等待最多 10 分钟，版本/help 各最多 5 秒。

**验证边界：** macOS arm64 实际只读探测为 `codex-cli 0.162.1`、`Claude Code 2.1.153`，登录/help 能力存在。合成进程测试覆盖完成、取消、超时、App 关闭、迟到核验、错误退出、来源修订变化、外部进程保护及脱敏；Windows 仅交叉编译，尚未原生执行。本轮没有运行真实官方账号登录，版本/help 输出不算授权验收；两平台实际官方页面操作、原生取消及命名空间验证留在 S1-T8／S3 验收记录中。

## 换号与结果核对

`confirm_change` 会先核验新身份，停止该平台旧授权 worker，持久保存原账号／目标账号／代次，再暂停并读回。Hive 要求设备在线，因此贡献已停止时使用本进程短暂连接完成换号；该连接拒绝所有 relay 目标，不改变“停止贡献”意图。

确认 POST 之前保存提交阶段；响应丢失后只核对目标指纹和严格递增一代的 generation，不重发确认。确认已证实后，同身份的新 token 可重新核验并同步；不同身份保留未决状态。同步、连接回收与本地保存全部成功后才删除未决操作，换号成功仍暂停。

停止贡献会取消并等待已受理的账号写操作，包括尚未建立连接的操作；普通刷新不会把尚未提交的换号自动提交，后端返回结构化 `confirmation_not_submitted` 时，才允许用户再次明确确认同一操作；已经提交但结果未知仍只核对。若连接已回收但清理标记保存失败，只允许本次管理实例凭该连接的确切 run／设备范围证明重试清理；跨进程异常恢复由恢复规则处理。
