# 桌面 AI 账号观察

原生「AI 账号」页可以检测 OpenAI／Claude 的官方登录，按需检查官方身份和额度，独立查看 Hive 账号与能力，并与概览共用暂停／恢复控制。本批不改变 Hive，也不启动贡献。接入、换号、撤销选择和完整移除仍受运行管理依赖阻塞；这些按钮没有假成功路径。

## 怎么使用

1. 打开普通原生客户端，进入「AI 账号」。页面只加载默认来源及公开快照，并核对 Hive；不会打开新的官方凭证或触发 Keychain 读取。
2. 在相应平台点击「检测已有登录」，读取本地官方来源。需要其他目录或存储时，先展开「高级来源」修改，再点击检测。留空保留默认命名空间，特别是 Claude 的默认 Keychain 身份；不要把显示的默认目录复制为自定义目录来代替它。
3. 点击「检查账号」才发起官方只读查询。它会重新读取来源并在查询后核对，换号或同号换 token 时丢弃本次结果。检测或检查均不刷新 token、不写回官方登录、不保存账号选择。
4. 点击「查看详情」，分别看本地候选、官方观察、Hive 当前／待确认账号、所有适用额度窗、模型和各自更新时间。OpenAI 本地身份不等于在线身份核验；Claude 需要官方 profile 成功才可显示身份已核验。
5. 「刷新 Hive 状态」只核对 Hive，不重新检测官方来源。Hive 离线不遮盖本地候选，设备核对失败也不阻止本地检测；但设备未核实时不能写供给状态。
6. 平台供给区与概览共享同一份状态。暂停不终止在途请求；恢复只解除手动暂停，不启动贡献。存在换号未决的平台禁止恢复，仍可安全暂停及 GET 核对。全部操作逐平台显示结果，一个失败不会抹掉另一个的成功。

官方授权入口尚未接通，请在对应官方客户端登录后重新检测。不要将密码、验证码或 token 填入 Bee；本页只接受目录和受控存储选项。系统通知尚未接入，不弹 OS 授权，问题仅在应用内显示。

## 来源、时效和失败

OpenAI 默认目录依次取 `CODEX_HOME`、用户目录下 `.codex`。`auto` 先读固定 `auth.json`，仅文件确实缺失且系统为 macOS 时才尝试 keyring；损坏或权限拒绝不回退。Claude 使用既有独立目录／NFC／Keychain 命名空间规则，`file` 与 `keychain` 不互相回退。macOS 以外的 Keychain 选项标记为不支持。本轮三端真实来源验收仍未完成。

编辑来源立即隐藏旧候选和官方观察；迟到结果不能覆盖新来源。候选只存在于当前管理实例，重新检测替换其修订号和随机引用，进入到期前 30 秒即失效。未知套餐显示未知，不能从套餐文字猜身份或接单能力。

官方观察按来源、指纹和凭证版本隔离：正常间隔 5 分钟、有效期 6 分钟、元数据缓存 5 小时，429 服从 `retry_at`。重复读取不能刷新原观察时间。单独的 profile 查询失败保留仍有效的独立额度结果，同时显示此次失败。额度百分比保留 120% 等原值，进度最多 100%，剩余最少 0；null 表示未知。专属 Opus／Sonnet 窗耗尽不能推导整个平台耗尽。

Hive 观察执行身份核验和 account → capabilities → account 夹读，核对指纹、generation、credential_revision、状态及未决账号。变化时整组未确认，不能混用两个账号的数据。`rate_limited` 是独立的当前事实，历史额度过期不会覆盖它。账号支持模型、市场开放、当前接单条件分别显示；没有可信市场接口时保持未知。

供给 GET 串行执行，成功后等 10 秒再刷新；概览与账号页之间切换不重建状态，离开这两页停止轮询。30 秒以上、核对中、失败或未核验状态禁止写入；每次实际发送全部操作中的下一项前也重查门禁。未知写结果停止自动刷新，用户点击重新核对仅发送 GET，不自动重放 PUT。

错误保留本次失败的检查点、HTTP 状态或系统证据，不回显官方正文、token、JWT、邮箱、confirmation_id 或连接 lease。一个子域失败不冒充其他子域失败或成功。

## 本地记录与命令

`ai-accounts.json` 位于独立桌面设备配置同目录，版本 1。本批仅持久化提醒去重，不保存来源选择、凭证或未来写操作状态机。文件受私密权限、禁止跟随符号链接、原子替换和读回保护；损坏或未知版本不会被静默覆盖。

提醒按 Hive／owner／platform／指纹／问题类型去重，设备只参与归属核验。持续离线满 60 秒才提醒；明确恢复后再次异常可以重提醒，未知和陈旧观察不当作恢复。写去重记录失败时保留问题并说明持久化未确认。重启不把历史观察显示为已选择或贡献中。

私有桥新增四个固定命令，详见[管理协议](bridge-protocol.md)：

| 命令 | 固定参数 | 行为 |
| --- | --- | --- |
| `account_defaults` | `{}` | 仅返回默认目录和存储能力 |
| `account_detect` | `platform,directory,store,mode` | `mode=local/official`，必须显式给出 `directory:null` 或绝对目录 |
| `account_snapshot` | `platform,refresh` | false 仅公开快照；true 只刷新 Hive |
| `account_action` | `platform,revision,candidate_ref,action,confirmed` | 严格校验；本批在任何副作用前返回缺失依赖 |

Go 操作总期限 12 秒；Rust 账号请求从进入队列起共 15 秒。未发出的排队超时不破坏健康会话；已发送超时先撤销 ready，拒绝迟到成功和后续排队写。前端仅使用 typed 命令，不扩展 generic `bridge_request` 的 ping 权限。

公开快照固定含 `platform/revision/candidate/selection/hive/authorization/capabilities/features/issues/checked_at`。Hive 额外公开 `pending_fingerprint/generation`，不公开 confirmation_id。能力按 official、hive 两项排列；所有时间为 UTC RFC3339（可含 1–9 位小数）或 null。前端逐字段解码，未知字段、错类型和错误实例不能进入视图。
