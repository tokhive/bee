# OpenAI 账号页对齐记录

本轮依据主预览 `docs/preview/index.html` 与用户认可的紧凑修订，修改正式 React 页面。原后台能力缺口仍见上一轮 `2026-11-10-openai-completion/README.md`，本记录不代表完整业务规格验收。

## 已修正

- 页头接入数量移至标题右侧，消除多余占行；Hive 控制台仍可从其他页面进入。
- 正常与凭证故障共用紧凑骨架，状态与动作同行；读取故障不额外展示步骤条。
- 已接入账号固定显示双窗口额度；真实百分比不被夹成 100%，未知为 —，历史数据保留标识。额度详情只显示重置信息，不重复进度条。
- 删除“查看接单条件”独立折叠；额度耗尽不作为通用操作失败。独立阻塞原因、必要导航和暂停事实继续保留。
- 错误详情单层展示经脱敏的错误码、检查环节和证据，无嵌套卡片、重复按钮。钥匙串缺失按 read_keyring/source_missing 明确提示。
- 详情、读取设置、新旧账号核对、安装说明使用独立面板；换号经核对后才进入现有安全确认。详情不再内嵌设置表单。
- 已接入账号的登录确认标题、重新打开登录页、过期登录入口及准备步骤与真实状态对应。
- 主预览同步紧凑修订；修改前、中间与最终完整单文件均追加归档。最终快照为 `20261110-171805-openai-compact-final`，171341 是中间版。
