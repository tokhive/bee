## 本轮发现与修复

- 原生启动上层提前拒绝脏会话／跨实例未知 journal，导致底层退役证明流程不可达。真实 `experience::startup` 入口回归先失败，修复后进入原有设备前置检查与持久退役证明流程；无证明、绑定不符、同实例未决及远端排空仍阻止恢复。
- 状态读取重试耗尽后仍显示进行中，旧后台未声明能力时显示无效核对入口。前端使用实际查询轮次状态与 capability，停止时立即允许人工核对，迟到终态仍能更新。
- Go 新增 5 个公开恢复错误码未同步到 Rust／TypeScript 诊断白名单。既有跨语言契约测试捕获失败；同步封闭白名单，继续拒绝未知值与敏感输入。
- Rust journal、Go retirement 元数据损坏时缺乏具体失败检查。改为逐项诊断并保留脱敏解析原因，不泄漏未知字段值。
- 原生体验验收示例未同步错误结构、设备绑定 revision 和通知语言参数，导致完整 `cargo test` 无法编译。补齐接口并复用生产语言类型；示例仍不创建业务 bridge/runtime。
- 账号预览跨轮次流程及测试与正式 OpenAI UI 漂移。修复未接入账号误显供给条件、缺失来源无登录入口、未知供给结果无纯读核对入口，以及设置打开焦点与未改值无法保存核验。打开／关闭设置不读写业务，保存才核验；同步模拟准备完成证据与最新暂停选择语义，保留历史场景。
