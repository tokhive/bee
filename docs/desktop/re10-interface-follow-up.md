# RE-10 接口后续待办

2026-11-07 收到已确认的 UI 方向：归属或原始记录不明、当前无法安全重启时，主入口目标为“重新登录”。该方向不授权 UI 覆盖 `actions.restart=false` 或直接重新发送启动命令。

本文件仅登记后续接口核实工作，不修改 UI 文档或 HTML，也不宣称已实现。

需在本轮接入供给保护完成后核实：

1. 现有账号维护入口能否重新取得原流程证据，且不重复 spawn、不误杀、不绕过未决占位。
2. 区分可重新取得证据的短暂失败与不可恢复的原始记录丢失。前者定义重新核实、恢复中、允许启动与仍受阻；后者明确真正可执行的恢复出口，不返回注定失败的可用按钮。
3. 如缺接口，补最小动作许可和返回约定；再次失败保留具体原因，不能承诺每种归属不明均可重试，不能以永久禁用或仅“查看诊断”结束。

需求定位：`accounts-preview-design.md` 的“登录取消与重新登录恢复：续评结论（LOGIN-13～15、RE-07、RE-10）”中 RE-10；以及 `account-scenarios.md` 的 RE-10。核实时读取其最新内容，保留 UI 会话的所有修改。
