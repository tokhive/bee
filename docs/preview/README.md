- **LOGIN-15／RE-10／RE-12**：归属不明或长期未知的实际恢复出口尚未闭合。无安全许可时展示阻塞证据，不伪造“重新登录”成功，不使用永远有效的重试按钮。RE-12 保留步骤，“刷新登录进度”只查询原操作。
