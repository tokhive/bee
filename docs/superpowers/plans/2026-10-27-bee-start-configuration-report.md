# Bee 启动配置自动检查实施报告

## 实现

普通“启动 Bee”取消是否引导的问题，先检查匹配服务与两个配置文件。已运行的服务直接提示；完整配置验证设备身份后直接按环境启动；缺配对自动引导或续配，缺供给自动选账号。

配置损坏、权限和读取错误携带路径及原因，不覆盖文件。设备 JSON 还会拒绝 null 和多余内容。仅 Hive 明确的 401/403 + device_replaced / invalid_device_credential 引导重配，保留最终确认、锁和私有备份；网络及未知错误停止本次启动，供给选择始终保留。验证期间设备配置被其他操作更新时拒绝重置。

官方客户端登录缺失不影响已有供给文件的复用，运行时仍可连接并等待恢复。高级前台入口保留仅在线模式、显式路径与启动确认。README、菜单帮助及配套文档站同步。
