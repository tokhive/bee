# Bee 管理菜单的排版与语言统一

## 目标与批准

用户已确认现有数字管理菜单可用，批准统一语言、紧凑排版、准确错误提示和简化返回操作，并授权自行决定适量 emoji 与配色。沿用菜单业务流程、确认、配对备份、服务匹配校验。

## 交互约定

- 每页一个标题、一条细分隔线；主菜单只显示 Bee 管理及六个入口，版本和配置路径放运行状态页。
- 青色标题和数字；绿色成功、黄色提醒、红色失败、灰色辅助信息。emoji 仅用于标题和状态。颜色不作为唯一语义；NO_COLOR 关闭颜色，TERM=dumb 使用纯文本。
- 主菜单 0 为退出，子菜单 0 为返回上级；子菜单返回、语言切换直接刷新父菜单，不额外要求回车。动作结果保留回车阅读停顿，取消选择直接返回。
- 语言切换立即作用于所有后续菜单标题、标签、状态、已知错误原因和下一步。品牌、命令、路径和机器码保持原样。
- macOS 等不支持 systemd 管理属于能力限制，显示中性提示及 bee start 指引。服务安全检查失败仍明确报告。
- Hive 的已知错误按 apiFailure 的 Code/Status 翻译；账号错误按稳定错误码和具体类型翻译，保留 HTTP 状态、路径、实际值。不对英文字符串作猜测性翻译。
- 未知外部错误和运行日志保留原文，单独标注技术详情；不把整条错误链涂红，不截断证据，不输出凭证。
- Codex 与 Claude Code 分别显示检测结果和对应登录指引。未检测到可用账号与用户主动跳过是不同结果。

## 技术栈（沿用，已确认）

Go 1.27.3 与标准库实现菜单渲染和结构化错误；沿用 ANSI 和现有 installUI 的终端识别，无新增依赖、无全屏 TUI。沿用 Go 测试、Python 3 PTY、ShellCheck 和 make test 验证；无需新增 CI 作业。旧 CLI 以及 doctor JSON 的字段保持兼容，菜单单独本地化。

## 验收

中英文真实终端均可连续操作；嵌套返回不吞掉下一次输入；错误原因和下一步同语言，未知证据仍可见；终端降级、取消和服务安全回归通过。更新现有 PR，不合并、不发布。
