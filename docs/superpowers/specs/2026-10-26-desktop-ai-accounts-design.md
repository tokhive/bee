## 1. 目的与范围

让用户在 Bee 的「AI 账号」页完成一整套账号管理：找到或登录账号 → 核对身份与套餐 → 选择接入 → 查看额度和模型 → 暂停／恢复 → 处理过期、换号和移除。检测已有登录只是其中一步。

沿用 OpenAI／Claude 两个平台、每个平台最多一个接入账号、一个 Provider 仅有一个有效 Bee 的已确认范围。首次接入后保持暂停，首次贡献由用户明确开始；按已确认的 D2，换号成功后也保持暂停，由用户再次点击「恢复贡献」。账号检测不自动启动贡献，不退出官方客户端，也不删除历史收益。

本文同时描述完整目标、现有能力和依赖条件。用户要求扩大 spec 不等于允许修改 Hive。当前仍按「不改 Hive」推进；缺少依赖的功能保留完整规则，不能用假成功、静默降级或删除需求来交付。

账号页内的贡献平台选择、暂停／恢复和运行前置条件属于本 spec；实际贡献进程的启动、停止、任务调度及退出由运行管理模块承接。Hive 登录、收益计算、资金操作和通用更新系统分别沿用原阶段设计。

## 6. 检测、核验和接入

### 6.1 检测已有登录

两个平台分别提供「检测已有登录」和「官方授权」入口。未绑定时可预览本地检测结果，同时显示绑定引导；持久接入和 Hive 操作必须先核验设备归属。

检测来源通过高级设置选择。OpenAI 默认目录依次为 `CODEX_HOME`、`~/.codex`，自定义绝对目录优先；默认先查 auth.json，只有文件确实不存在且系统为 Mac 才尝试直接 Keychain。存在但损坏、不可读时停止；明确选择 file 或 keyring 时不回退。沿用 Codex 的目录规范化和 Keychain 命名规则。

Claude 默认存储为 Mac Keychain、其他系统 file；目录沿用 Claude 的默认环境及显式命名空间规则。null 表示默认命名空间，自定义目录为非空绝对路径。保持 NFC 和不解析路径别名的 Keychain 命名方式；读取 Keychain 失败不自动换成文件。两平台不能共用一套目录规范化规则。

只读取固定官方文件名或固定算法生成的 Keychain 项。不接受凭证文本、任意文件名、Shell 参数或任意 URL。目录拒绝控制字符、相对路径及超过 4096 UTF-8 字节的值；不自动修改权限。Windows/Linux 未支持的存储方式显示「暂不支持」，不能显示「未登录」。

按已确认的 D1：进入页面只读公开快照，不擅自读取新的官方来源或弹出授权；第一次读取、切换来源由用户明确点击。已经选择且明确允许 Bee 使用的来源，可由运行同步按既有机制读取。检测不会保存选择或启动贡献。

### 6.2 核验身份与授权

本地检测显示来源、套餐、到期时间和短指纹。OpenAI 的本地身份来自结构校验，不能称为官方在线核验；Claude 需要既有 profile 查询后才能取得可靠身份指纹。

「检查账号」可调用既有固定官方 profile／能力端点。调用前后重读来源并比较账号及授权版本，变化时丢弃本次观测；过期或缺少所需权限时停止。不同来源的失败分别显示，不用 Hive 离线遮盖本地结果，也不把本地成功显示为 Hive 已接入。

官方查询不发生成请求、不刷新 token、不写官方登录。未知套餐显示「未知套餐」；公开 DTO 使用现有受控套餐名，不回显凭证内任意字符串。过期边界沿用当前时间加 30 秒；是否有 refresh token 不作为「可用」的替代证明。

### 6.3 选择接入和重启恢复

用户核对平台、候选标识、来源及影响后点击「接入账号」。Go 重新核验设备和候选，防止确认时官方来源已换号。Claude 身份未核验时不保存一个未知账号作为已确认选择。

设备属于外部管理的 Bee 时，只提供检测和状态查看；在运行归属明确且用户完成独立的复用／接管流程前，不通过接入账号操作暂停外部供给或更改其来源。运行归属未知时不能假设本机尚未运行。

桌面使用独立受保护的 `ai-accounts.json`，位于已有桌面设备配置目录；不覆盖 CLI egress。按 Hive、owner、device、platform 隔离，记录格式版本、修订号、来源描述、已确认指纹、选择／移除状态、未决操作和通知去重标记；不保存官方 token、原始 JWT、邮箱或 API 响应。

该文件是桌面账号选择的唯一来源。运行管理从已核对的选择构造内存 egress，复用现有构造与验证；不再写第二份可独立修改的账号选择。原子替换和读回成功后显示「已选择，待同步」。当前已有 CLI 配置保持独立，复用它必须由单独明确操作处理，不能自动搬入。

接入确认包含「保持暂停」：先保存含候选、预期修订号和账号归属的 prepared 操作记录，保留原选择；再通过既有供给控制确认 paused=true，最后提交本地选择并读回。遇到网络或落盘结果未知时，恢复同一操作并只做核对，不重复发送写请求。已处于暂停也需新鲜回读。保存失败保留暂停并说明本地选择未确认，不自动恢复接单。

已有其他接入账号时不能用首次接入覆盖它，必须走换号流程。运行管理已经使用当前选择时，变更先取得明确的来源切换屏障；只有从未启动或已核实停止、且无未决同步的本地选择可直接更新。未知运行状态拒绝变更，不能仅凭窗口关闭或管理进程 ready 判断安全。

运行管理核验来源、身份与选择修订号后负责同步；账号页只有在 Hive 当前指纹和本地选择一致、授权状态可确认时才显示「已接入」。首次启动必须由用户明确操作。重启恢复选择及未决记录，再核对身份；不以本地保存记录直接恢复「已接入／贡献中」。

### 6.4 授权维护与重新登录

页面刷新只更新观察结果，不能触发令牌续期或改写官方登录。运行期间的授权维护由既有 Go 同步机制承接，接入说明需告知所选来源是否支持续期及可能写回官方存储；账号页展示维护中、待同步、需要官方客户端更新等真实状态。

当前 OpenAI 文件来源已有续期写回，Keychain 来源需由官方客户端更新；Claude 沿用现有存储适配、锁和维护记录，不能将某一来源测试通过外推到所有系统。OpenAI 文件写回源码已注明官方客户端不共享 Bee 锁，仍存在跨客户端竞争；在运行管理集成前需验证这一限制的处理，不在本稿中宣称竞争已解决，也不承诺所有来源均可自动续期。

同一账号更新授权版本不属于换号：核对指纹不变后更新授权状态、废弃旧能力并重新同步，保留原主动暂停选择。续期结果未知、保存失败或授权被拒绝时显示具体恢复入口，不从账号页重复提交续期。需要重新登录时引导用户到已验证的官方入口，完成后重新检测；若身份改变则进入第 10 节换号确认。

## 7. 官方授权入口

两个平台都属于完整目标：用户从 Bee 发起 → 在对应官方界面完成登录／授权 → 返回或重新打开 Bee → 核验本次结果 → 用户明确选择接入。取消和失败不覆盖原账号，不自动开始贡献。

官方授权适配开放前，必须核验：平台提供的启动方式、应用身份与适用权限、回调或完成检测、取消／过期行为、官方凭证存储位置、与已有官方客户端共存，以及三端适用范围。不得猜测授权端点、复制其他应用 client_id 或用网页 Cookie 充当桌面授权。

本项目现有源码只有官方登录读取和续期能力，没有可复用的完整首次授权适配。因此当前具体适配方式未选定，不能把这部分写成已可执行任务。若采用已安装官方工具引导登录，只能标为「前往官方客户端登录」；它不等于 Bee 已实现独立 OAuth。若需专用桌面 OAuth，则先补齐已验证接口、回调安全与依赖，再请用户审阅本 spec 的变更。

在适配未通过验证时，入口显示真实可用状态和已有登录的处理方式。授权完成仅触发重新核验；原账号、新候选、确认选择各自保留，不靠「浏览器已关闭」判断成功。

## 8. 额度、模型和数据时效

详情面板展示账号标识、订阅套餐、授权、接入来源、全部适用额度窗口、重置时间、模型列表及各数据更新时间。账号详情不展示买家身份、请求／响应正文或逐次请求用量。

额度沿用 `beewire.Capabilities`：窗口包含 scope、秒数、used_percent、reset_at；使用率单位是百分比，不再除以 100。数据可能超过 100%，原值必须可见；进度条最多填满，剩余比例最少为 0，不将超限值伪造为正常。null 或无效字段显示未知，不能显示零。OpenAI 不同套餐的单窗口／双窗口及 Claude 的五小时、周、模型专属窗口按现有校验展示，不硬编码成统一两行。

额度常规观察间隔沿用 5 分钟、有效期 6 分钟；套餐／模型元数据沿用 5 小时缓存及既有有效期校验。手动刷新也服从 retry_at 和限流期限；禁用期间给出可再次查询的时间。过期可展示带时间的历史值，但不能用来判定当前可接单。

已接入账号优先读取 Hive 已接受的能力；候选账号的直接官方查询独立标记为「官方观测，尚未同步」。不在每次页面轮询中重新请求官方额度。账号指纹、代次或凭证版本变化时废弃旧能力；保留原数据不代表可归属到新账号。

Hive 的 account 和 capabilities 是分开读取：读取前后核对 account 的指纹、generation、credential_revision；发生变化则整组结果未确认。capabilities 读取返回 unknown 或失效原因时按真实语义解释，不能套用报告入参的 ready schema 将所有返回都误判为协议错误。

模型的三项事实分开：账号支持、Hive 市场开放、当前可接单。账号支持来自能力数据；市场开放必须来自可信 Hive 数据，不能从供应列表、模型名称或账号支持推断；当前可接单还受暂停、运行、授权、额度等条件影响。

当前设备鉴权 capabilities 没有逐模型市场开放信息；网页登录的 DeviceModels 返回 tradable 也不等于管理员的 enabled。此项依赖适当的 Hive 只读接口或后续桌面账号会话，当前显示「市场状态未知」。不传网页 Cookie、不要求用户提供管理员或买家 API key，也不越权复用 `/api/models`。

## 9. 暂停、恢复和贡献平台选择

账号卡片和概览共用既有 SupplyClient，不保存两套暂停状态。明确作用范围为当前 Hive 用户的平台接单许可；暂停不终止在途请求。恢复只解除暂停，不启动运行、不改变接入选择、不跳过其他接单条件。

「全部暂停／全部恢复」顺序执行两个独立平台操作，各自显示成功、失败、未确认；一个失败不回滚另一个的成功，也不把整个批次显示成功。失败写入只允许查询核对，不自动重发。

供给状态成功后按已有 10 秒节奏串行查询，超过 30 秒、核对中或失败时禁用基于旧状态的写入。新接入、换号、移除未决时不能恢复该平台。平台贡献选择来自本地已确认账号记录，实际开始贡献交给运行管理处理。

## 10. 换号

发现官方来源身份与已确认指纹不同，保留原账号和新候选，显示「待确认换号」；旧能力立即失效。不得自动跟随新账号、自动接回已移除账号或将新身份沿用旧账号的运行选择。

尚未同步的本地选择可在运行管理证明未使用该选择时重新选择。已由 Hive 注册的账号，必须由实际运行的 Bee 报告候选并获得 Hive confirmation_id；仅在页面检测到另一文件不足以构造服务端换号请求。外部管理的 Bee 只显示状态和归属，不自动接管、改其配置或确认其候选。

确认流程：展示旧／新短指纹及影响 → 保存本次操作记录 → 确认暂停成功 → 再读 pending、设备归属和来源 → 使用同一候选与 confirmation_id 调用既有 confirm → GET 回读指纹与 generation → 等运行同步新授权。每一步失败或未知保留具体阶段，旧账号不能提前消失；新账号未同步前不显示已接入。

运行管理发现新身份时只报告候选，用户确认前不能用新账号接单或维护其授权。服务端换号结果核实后，再按预期修订号原子提交本地新来源／指纹并读回，随后允许运行管理按新修订同步；旧选择保留在操作恢复记录中。服务端已切换但本地保存失败时保持暂停及未确认状态，重启继续核对同一操作，不能把旧本地选择回写服务端。

确认请求由 Go 持有完整 confirmation_id，不交给前端当任意写参数。重复／迟到确认、候选替换、撤销设备、来源再次变化必须拒绝。POST 响应丢失后先查询原操作；不得生成新候选或自动重发。只有目标指纹和预期代次等证据一致才可确认结果；仅指纹相同但中间又换过账号仍需显示未确认。

取消确认窗口只取消尚未提交的用户意图，不撤销官方客户端的登录变化。按已确认的 D2，换号成功且新账号同步完成后仍保持暂停，即使换号前正在贡献也不自动恢复；用户再次点击「恢复贡献」且实际运行、授权和接单条件核对成功后，才可恢复接单。历史收益归属和流水保留。

## 11. 移除、撤销选择和恢复

未注册、未交给运行管理的本地选择可执行「撤销本地选择」：经所有权和修订号核对后写入已移除标记。该操作不声称解除 Hive 上已存在的账号。若 Hive 或运行状态未知，不能将此路径当作已注册账号移除的捷径。

完整「移除账号」必须满足：停止该账号新任务并获确认 → 核对真实在途执行结束 → 停止来源同步并解除 Bee 接入凭证 → 保存已移除标记 → 核对后显示未接入。移除不会注销官方客户端、删除其文件、撤销官方订阅或删除历史收益。重新接入必须再次明确选择。

当前没有满足以上步骤的完整账号移除／收尾接口；`account/source` 只代表来源不可用，平台 paused=true 也不能证明在途结束。因此在当前不改 Hive 的边界下，已注册账号的移除入口说明缺少支持，不发送半套操作，不先删本地选择。运行管理和后端具备该能力后，按本文完整语义接通；在此之前 A10 的完整验收保留未完成。

具备依赖后，操作按 prepared、quiescing、draining、detaching、completed 及 uncertain 记录阶段；阶段表示已有证据，不能单靠等待时长推进。首次外部修改前持久保存操作 ID、Hive/owner/device/platform、旧指纹和原请求参数。断线／重启查询同一操作；记录持久化结果未知时先读回，不重复写外部状态。

移除前确认可取消；一旦执行了暂停或解除，关闭对话框不等于取消业务操作，页面保留核对入口。若后端没有可证实的撤销语义，就不提供「撤销移除」按钮。完成后迟到响应不能复活账号；未决操作不能被新接入／换号覆盖。

## 12. 错误、刷新和通知

分别表达来源缺失、权限拒绝、存储不支持、登录过期、官方拒绝、额度限流、Hive 离线、身份变化和操作未确认。错误包含失败检查、平台、实际 HTTP 状态／系统退出码／字段类型等公开证据；绝不输出 token、原始授权、请求正文或完整系统凭证内容。

来源拒绝不能归为「未登录」；一次请求失败不能归为「账号已失效」；未知额度不能归零。重新检测／刷新只发起安全读取，不能顺带确认换号、删除账号或重放写入。编辑来源、切换账号或管理实例改变后，迟到结果不得覆盖新状态。

账号页、详情、概览使用同一份有来源和时效的快照。部分读取失败保留各部分真实状态；写操作只依据新鲜且归属一致的结果。页面中英文、键盘、860×600 和深浅主题沿用 P1 标准。

授权失效、待确认换号、持续离线、额度耗尽产生账号提醒。去重键为 Hive/owner/platform/指纹/问题类型，问题恢复后允许下一次出现再次提醒；反复刷新不重复弹。离线持续 60 秒再通知；瞬时读取失败在页面即时显示。通知只含平台和问题，不含账号秘密或买家内容。

应用内提醒由本模块提供；系统通知遵守全局开关和 OS 权限，默认不擅自弹授权。用户关闭通知不隐藏页面问题。全局系统通知能力未接通前，这部分明确保留依赖，不以应用内提示冒充系统通知已实现。

## 13. 接口、持久化和并发边界

Go 提供结构化账号服务；Rust 仅转发白名单；React 不构造 Hive URL。以下为本 spec 的职责契约，具体类型名及文件拆分在获批后的 plan 中落实。

| 操作 | 允许输入 | 输出／约束 |
| --- | --- | --- |
| 来源默认值 | 无 | 两平台默认目录、存储枚举、OS 支持能力；不打开凭证 |
| 检测／官方核验 | 平台、目录 null 或绝对路径、平台存储枚举、明确的 local/official 模式 | 本地候选公开快照；无配置写入或贡献副作用 |
| 读取账号概览／详情 | 平台、是否请求安全刷新 | 已选择状态、来源、Hive 同步、额度、模型及各部分时间／错误 |
| 选择／换号／撤销本地选择 | 平台、当前快照修订号、Go 返回的候选／操作引用、明确确认 | 返回已确认阶段或未确认状态；拒绝过时来源和实例 |
| 已注册账号移除 | 同上，且必须具备运行与后端能力 | 完整持久操作；依赖未满足时在任何副作用之前拒绝 |
| 核对操作 | 本地操作 ID | 只核对原操作，不产生新业务操作 |
| 官方授权 | 平台及已验证适配模式 | 只有适配通过核验后才开放；无任意 URL／Shell 参数 |

公开快照包含平台、来源、选择修订号、短显示标识／公开指纹、状态、套餐、有效期、数据来源、观察时间、额度窗口、模型三项事实及功能可用性。状态分别保存，不将候选、已接入及运行状态压成单个枚举。错误是结构化公开信息；原始凭证、confirmation_id、连接 lease 和授权事务秘密留在 Go。

每个 Hive/owner/device/platform 的变更串行，文件更新带预期修订号和原子替换。网络期间不能仅靠过期锁推断旧操作停止；新变更前核对未决操作与实际运行所有权。聚合两平台操作各有结果，不增加跨平台事务。

快速读取／修改沿用 Go 12 秒总期限及桥 15 秒期限；官方查询也受该请求 context 限制，超时保留失败或未知。长授权／未来移除通过持久操作 ID 查询进度，不占满桥请求直至任务结束。重试仍遵守第 10、11 节，不建立无限自动重试器。

所有新参数拒绝未知、重复、缺失及错类型字段；source 与 platform 组合、时间、指纹、generation、额度单位均需校验。运行管理只消费已核验选择及修订号，不能绕过 removed 标记或自动选择检测到的其他账号。

## 14. 验收要求与用户需要做的事

以下均为未来实施验收要求，本次文档修改没有执行这些测试。

| 功能 | 必须验证的结果 |
| --- | --- |
| 检测与核验 | 两平台有效、过期、缺权限、丢失、无效结构、来源切换、文件／Keychain边界；本地成功不冒充官方／Hive 成功 |
| 接入与持久化 | 明确确认、暂停读回、账号变化拒绝、保存失败和读回、重启、Hive/owner/device 隔离；不改 CLI／官方文件 |
| 授权维护与恢复 | 页面刷新无续期副作用、同账号授权更新不误报换号、各来源支持范围、官方客户端并发更新、续期结果未知和重新登录；保留主动暂停 |
| 额度与模型 | 全部窗口、null、超 100%、重置和缓存过期、429 冷却、身份代次变化；未知市场信息不显示已开放 |
| 暂停与恢复 | 与概览一致、部分成功、超时只核对、不启动贡献、不清除已有暂停 |
| 换号 | 新候选、取消、过时确认、重复、响应丢失、确认后仍待同步；旧能力不套到新账号；换号前正在贡献也不自动恢复，换号及同步成功后须用户再点恢复 |
| 移除 | 能力缺失时无副作用；具备后真实停止新任务／收尾／解除、崩溃恢复、迟到结果、显式重新接入、保留历史与官方登录 |
| 官方授权 | 每个平台实际验证首次授权、取消、过期、返回、账号变化与原有登录共存；未开放不得假成功 |
| 提醒与页面 | 去重与恢复、通知关闭、中英文、860×600、键盘与焦点、深浅主题、演示隔离 |
| 安全与原生 | 标记秘密不进入输出／日志／前端；外部 Bee 不受接管；新包来源和签名；三端已有／新增证据分别记录 |

开发和自动测试使用本地服务、合成凭证与受控来源，不向用户真实平台自动发送换号／移除／贡献操作。只有代码和本地测试准备好后，才安排真实官方登录与账号操作验收；届时直接说明要打开哪个官方工具、登录哪个测试平台及可能出现的系统权限选择。用户不用提交密码、验证码或 token。

完整 AI 账号模块验收必须覆盖 A01–A12；现阶段缺依赖的功能记为未完成，不能因其他功能测试通过而将整个模块勾完。
