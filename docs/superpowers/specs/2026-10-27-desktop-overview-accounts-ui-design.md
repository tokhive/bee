## 1. 这次要得到什么

用户打开应用后，在概览的紧凑账号行看清每个平台的账号、套餐、额度、能不能接单和原因，并用一个按钮开始或停止贡献。账号的登录、接入、换号和凭证读取方式在 AI 账号页完成。暂停接单和恢复接单两页都能做，而且只在贡献已经运行时出现。

## 2. 范围

改侧栏、概览、AI 账号页。诊断和设置仍留在侧栏，页面内容不在本稿。去掉「收益」入口。概览打开时继续使用已经在读的供给状态和账号快照，不新增模型目录请求。报告过期后的自动核对复用既有读取入口，合并正在进行的请求，并沿用已有重试、限流和官方读取上限。

沿用已确认页面栈：React 19.2.8、TypeScript 7.0.2、Vite 8.2.4、现有 Radix／Lucide／Tailwind，用于页面、弹窗、图标和样式；本次不新增依赖或服务。保留既有 Tauri 原生壳和 Go／Hive 协议。

已批准行为继续有效：接入后平台保持暂停；换号成功后仍暂停；恢复不启动贡献；停止贡献要确认，并说明可能打断正在处理的任务。

2026-10-29 补充确认：后台刷新与用户操作状态分离。当前数据仍有效时，正常读取保留现有界面、按钮样式和可用性，不因轮询短暂禁用按钮或展示加载提示。执行用户操作时立即占用操作锁，直到提交及读回结束，防止重复提交；状态过期、读取失败、操作结果待确认或前置条件不满足时，继续按既有规则反馈并限制相应操作。点击与已有读取重叠时，等待读取结束后重新核对状态，仅在原操作意图仍适用时提交一次；读取失败、相关身份／候选／绑定变化、过期或页面实例失效时不继续写入。失败提示保留到成功核实，自动恢复始终只重试读取。

打开 AI 账号页时自动读取本机已有登录，不显示「检测已有登录」。账号接入后，额度和模型在后台读取并更新进度条，不显示「检查账号」，也不挡住页面。详情不列出模型名。钥匙串需要授权时再提示，不把这次读取做成日常按钮。

本稿改变的一点：开始贡献不再附带「本次恢复哪些平台」。它只建立连接并同步账号，平台保持暂停。用户要接单时，在贡献运行后单独点「恢复接单」。

### shadcn/ui 组件方向（2026-10-28 已确认）

采用 shadcn/ui 风格的紧凑按钮、描边标签、细额度条、输入框与 Radix 弹层。优先复用 Bee 已有组件、Radix 语义和样式变量；对照 [组件源码](../../../../../docs/ui/bee-theme-prototype/src/ui/) 及 Hive 现有 Button、Badge、Progress，按 Bee 的现有 CSS 组织适配，不引入整套主题库或为类名工具新增依赖。React、Radix、Lucide、Tailwind 与 Tauri 均为沿用且已确认，Node 24.x 用于构建验证。

主操作在浅色主题使用深色实心（参考 `#30312e`）和浅色文字，深色主题使用浅色实心（参考 `#e5e3dc`）和深色文字，保持高对比。次要操作使用描边或弱化样式。银白底色继续保留，琥珀色只用于导航强调、状态点缀和额度条，不把主按钮改成琥珀实心。运行主按钮 32px 高，账号行操作 25px 高；按钮 6px 圆角，列表约 9px 圆角和细边框；最终尺寸服从上面的已批准布局。

三方案比较未建立另一份业务 spec；本文是正式 App 布局、交互与视觉选择的统一规格。视觉参考源码含模拟状态，正式实现继续使用真实模型。

正式 App 使用系统标题栏，不复制网页预览宿主、场景选择器和仿制窗口按钮。最小 860×600 窗口下，额度组可移到同一账号行的下一层，长原因自然换行，页面和详情可滚动；不以截掉原因、隐藏操作或显示横向宽表来维持原型比例。

四项：概览、AI 账号、诊断、设置。没有收益。诊断和设置的点击目标不变。

## 4. 概览

从上到下依次为页面标题、运行摘要、设备摘要、平台账号列表。概览标题下不放副标题。设备是单独一板块，不放进平台列表。按指定原型摘要区的三列结构展示，保留列间细线和上下分隔线，每列为标签、内容、辅助说明。已绑定时三列依次为设备名称、归属邮箱、Hive 地址；等待网页确认时三列依次为配对码、有效期、确认网址，第三列附「打开确认网页」。两种绑定情况不会同时出现。不再使用单行设备信息条，不在这里放设备 ID 或贡献按钮。设备文本字号适配名称和邮箱长度，窄窗口允许换行。

运行摘要按指定原型排列：左侧图标、标题与说明，下方一行显示 Bee 运行和 Hive 连接，右侧只放一个贡献主按钮，不再另放连接徽标。左侧表达「贡献尚未启动／贡献已启动」，不据此声称平台可接单。进程没在跑时，状态行写「Bee 未运行」「Hive 未连接」，按钮为「开始贡献」；进程在跑时按钮为「停止贡献」，状态行按实际连接显示「Hive 已连接」或「Hive 未连接」。停止仍先确认。未满足已有绑定和账号接入前置条件时，不开放开始贡献。

下面是一个共享列表面，一行一个平台，顺序为 OpenAI、Claude。取消独立多列表头，将信息按原型组织成左侧身份与状态、右侧额度两列，账号操作在额度下方靠右。字段保留如下：

| 字段及位置 | 内容 |
| --- | --- |
| 平台，左侧 | 原型平台图标旁显示 OpenAI 或 Claude |
| 账号，左侧 | 平台名下显示已保存选择的身份前缀；没有选择时为「尚未接入」。不显示邮箱 |
| 套餐，左侧 | 平台名旁的小标签展示已有快照中的套餐；没有时为「未知套餐」 |
| 额度，右侧（窄窗口下移） | 每个已有窗口独立一组，名称与已用百分比在同一基线，下面为原型的细进度条。OpenAI 先「5 小时」，再「7 日」。没有观察时为「尚未核对」，不伪装为已用 0% |
| 接单，左侧身份下方 | 标题一次只有一个：可接单、不能接单、状态待确认、状态待更新。可接单要贡献正在运行、该平台没有暂停、报告新鲜且没有原因。不能接单时在标题下逐条列出全部原因。尚无报告时为「状态待确认」，报告过期或核对失败时为「状态待更新」；这些情况不显示旧的接单结论。报告仍新鲜时的后台核对可以保留有效结论。原因句子见[概览状态说明](../../../../../docs/discussions/2026-10-28-bee-desktop-supply-states.md) |

贡献未运行时，行尾没有暂停／恢复按钮，也没有手动核对按钮。不能接单的原因照常显示，其中包括未连接。

贡献运行中，已接入的平台在行尾显示「暂停接单」或「恢复接单」。恢复接单只解除该平台的手动暂停，不重新启动贡献。尚未接入的平台没有这个按钮。报告过期后自动发起只读核对，不显示「重新核对」按钮，也不提示用户处理正常过期。核对失败后继续自动重试，进行中的请求合并，沿用既有重试间隔和限流；不增加「重新核对」按钮。

账号列表标题右侧在过期报告正在核对时显示轻量的「核对中…」。核对失败后自动重试：等待间隔时显示「等待自动重试…」，请求执行时显示「重试中…」；成功后收起提示并显示最新接单结论。首次加载和报告仍有效时的正常后台核对不显示该进度提示；如核对失败，则进入上述自动重试状态。自动核对不改变账号选择、贡献运行或暂停状态，也不自动重放接入、恢复等写入。

概览不放登录、接入、换号、凭证读取方式，也不放「全部暂停」「全部恢复」。

## 5. AI 账号

复用概览的紧凑账号列表和原型的账号页标题、辅助说明、平台图标、套餐标签；动作组放在额度下方靠右，一行一个平台。账号、套餐、额度和接入状态的词与概览相同。已有功能信息较多时账号行可以增高，保持每个平台一个整体。

行尾同类主操作按钮尺寸一致，采用原型紧凑按钮；详情入口采用右箭头图标，提供「平台名 详情」可访问名称及提示，不为缺失动作保留宽大的空白按钮槽。还没有登录时，主按钮是「登录 OpenAI」或「登录 Claude」，原因写「还没有 OpenAI 登录」或「还没有 Claude 登录」。点下去仍先确认，并说明会打开对应官方客户端。已经读到登录但还没接入时，主按钮是「接入」，原因写「已有登录，尚未接入」。已经接入时，行尾不再放读取按钮。

接入仍要确认。确认后保存选择，平台保持暂停。

「详情」始终在主按钮旁边，没有主按钮时仍占同一个位置。换号和取消接入放在详情里。取消接入只在这次选择还没注册到 Hive 时出现。已经接入后，再登录一次官方客户端也从详情进入，按钮写「重新登录」。已注册账号的完整移除仍不做。

详情沿用原型的右侧面板和轻遮罩，关闭、Escape、焦点约束及关闭后返回触发入口均保留。信息按标签与值的横向行排布；空间不足时纵向滚动。当前只有一组详情内容，不恢复原型的模型标签页。确认操作沿用原型约 400px 的简洁弹窗。

「凭证读取方式」只放在该平台的详情里，打开详情时默认展开。它指定目录和存储方式：目录留空就是官方默认位置；OpenAI 的存储方式是自动、文件、钥匙串，Claude 是文件、钥匙串。当前系统不支持的方式显示「暂不支持」。这里读取官方客户端已经保存的登录，不粘贴密钥。账号行上不显示。目录留空就是要贡献的登录时，不用改这两项。官方登录不在默认位置，或默认位置里的登录不是要贡献的那个时，在这里修改。改完后重新读取登录。已经接入的账号不会因此自动换成新位置里的账号。

详情其余内容只补账号行上看不到的信息：当前账号的身份前缀、套餐、授权到期时间、每个额度窗口的重置时间。授权到期时间一直显示，没有到期时间时写「未知」。换号时写「当前账号」和「要换成」，都用身份前缀。报告过期或核对失败时自动核对、重试，详情显示与列表相同的核对或重试状态，不放手动核对按钮。不列出模型名，也不展示 Hive 代次、元数据时间、更新时间、观察有效期、下次可检查时间、官方观察和 Hive 观察两套标题、市场开放，以及原始错误码。

账号操作正常进行时保留短间隔读取；结果待核对或读取失败后，每 10 秒通过已有刷新快照入口核对，不再次提交账号动作。凭证来源的权限或读取失败保留诊断证据，修复访问条件后重新进入账号页会再读一次；停留页面期间不反复触发系统授权。

已接入且贡献未运行、报告新鲜时，行内用文字写「已暂停」，没有暂停接单按钮；报告尚无、过期或失败时仍显示对应待确认状态。尚未接入不写「已暂停」。贡献运行中，已接入的平台在主按钮之外再显示「暂停接单」或「恢复接单」，与概览写的是同一个供给状态。

## 6. 设计核对与实施验收

- 功能逐项覆盖：设备配对／已绑定、自动读取、官方登录、接入、开始／停止、分平台暂停／恢复、换号后暂停、取消未注册选择、授权到期、额度窗口和重置、来源设置、过期自动核对、正常核对保持安静、过期核对及失败重试显示状态、核对失败后的自动重试。
