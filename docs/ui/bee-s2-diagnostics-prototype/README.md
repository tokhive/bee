# S2 诊断页布局预览

这是供用户选择布局的临时 UI 原型，使用已批准的银白精工公共壳、Bee 样式变量和 shadcn/ui 按钮层级。它不修改正式 UI，不读取真实账号，不调用 Bridge，不进行网络诊断或系统操作；所有数据和交互都在内存中。

从 S2 工作树根运行：

```sh
python3 -m http.server 1432 --bind 127.0.0.1
```

打开 `http://127.0.0.1:1432/docs/ui/2026-10-28-bee-s2-diagnostics-prototype.html?variant=A`。

- A：按设备、OpenAI、Claude 分组，原位展开检查证据。
- B：检查项列表与详情并列，集中查看原因和公开证据。
- C：优先展示需要处理的平台，其余检查保留在折叠分组中。

三版使用相同的 16 项合成检查：10 项通过、3 项失败、1 项提醒、2 项未检查。保留「检查结果／安全日志」页签。页签本身不触发诊断或日志读取；诊断与日志分别通过明确按钮触发模拟动作。导出范围弹窗不写入报告文件。

底栏切换 A／B／C，方向键也可切换布局；顶部可切换明暗主题和未运行场景。地址参数为 `variant=A|B|C`、`theme=light|dark`、`tab=checks|logs` 和 `scene=completed|empty`。

正式实现需在用户选定布局、中文规格及实施计划获批后重新接入现有真实功能，不能迁入本原型的模拟逻辑。公共壳外观参考已批准原型；S2 正式公共壳尚未同步的改动不在本原型中写入正式组件。
